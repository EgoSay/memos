# 分区 Webhook 配置、自动外发触发与可见状态

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

现有 Webhook 为用户级分发，不能保证只有特定个人分区外发。用户希望一次配置后自然自动执行，而非每条确认。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 按分区配置一个或多个具名目标、签名与事件策略；填写地址不等于启用，测试默认发送不含私人资料的示例。
- 启用时明确授权未来完整保存的新内容自动发送；历史默认不补发，另选批次才补发。
- 正文与附件全部完成后才触发；移动已有记录进入已启用分区形成可追踪事件，避免重复帖子。
- 更新默认本地改动待主动发送，可另启自动更新；撤回独立配置默认关闭并展示目标能力。
- 暂停取消待发/重试且不暗中积压新队列；恢复默认只对未来生效，历史需主动补发。
- 删除、归档、移出或分区删除停止相关待发正文；已发送副本撤回结果独立展示。

## UI 与交互规范

- 分区编辑器显示目标和“保存并同步”，不重复审批；普通编辑器不沿用外发分区。
- 区分已保存、待发送、Webhook 已送达、发布结果未知、已发布、失败与暂停。

## 验收条件

- [ ] 普通记录不触发外发，未完整附件不外发；启用不重放历史。
- [ ] 配置测试没有私人数据；多目标状态可分别查看。
- [ ] 暂停、恢复、移出和删除符合授权状态，Webhook 200 不直接显示社媒已发布。

关联总需求验收：AC28、AC29、AC31、AC32。这些是未来验收条件，当前没有勾选为完成。
