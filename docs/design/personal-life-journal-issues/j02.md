## 背景与目标

最常见的动作只是留下一句话。标题、分类和保存后的附加任务会增加负担；多年后的日期与原文必须可信。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 直接录入文字并显式保存；标题、标签、心情、位置均非必填；空白禁用保存，有有效媒体可无正文保存。
- 保存原话，不自动润色、起标题、总结或关联。格式、标签、日期调整放次级入口。
- 区分本人指定记录时间、实际录入时间、修改时间和时区；补记可调整日期，导入时间不伪装原始写作时间。
- 提供日期排序、关键词及日期范围搜索，标签可选；离线查询说明仅覆盖缓存的实际范围。
- 草稿与正式记录区分；普通新建不继承上次外发分区，分区内新建显示归属及同步目标。

## UI 与交互规范

- 默认“记录 / 随便看看”结构待原型确认；详情返回恢复筛选、滚动和展开状态。
- 建议 Cmd/Ctrl+Enter 保存、Enter 换行，中文输入组合态不误触发。
- 保存反馈就近且中性；无音效、庆祝或下一项任务。

## 验收条件

- [ ] 一句话可以直接保存，内容不被系统改写。
- [ ] 补记、编辑和导入后，显示日期与真实时间元数据含义一致。
- [ ] 关键词、日期及可选标签能找到已有记录；返回不丢位置。
- [ ] 移动端键盘不遮住保存，中文输入法、键盘导航和大字体可操作。

关联总需求验收：AC01、AC03、AC04、AC22。这些是未来验收条件，当前没有勾选为完成。
