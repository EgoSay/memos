# 个人分区及安全的归属与删除语义

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

现有 Space 面向成员协作，删除空间会连带删除记录；这与个人资料容器的预期不一致。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 分区只用于本人组织和配置外发，不需要邀请成员；新分区默认私密且不启用同步或分享。
- 建议单条最多一个分区、允许未分区及多个标签；全部记录仍是统一入口。
- 分区、分享授权、同步授权相互独立；移入分区不等于公开整个分区。
- 删除分区应保留记录转为未分区，停用对应规则并取消待发，不沿用连带删记录行为。
- 普通新建不记住上次外发目标；已有草稿保留明确归属，分区内新建清楚显示。

## UI 与交互规范

- 归属是可选操作，不要求每次分类。
- 已启用同步分区显示目标与“保存并同步”；不加每条重复确认。

## 验收条件

- [ ] 未分区记录可直接保存，新分区无隐含外发。
- [ ] 删除分区后正文和媒体仍在全部记录中，相关待发停止。
- [ ] 迁移已有 Space 时明确成员、可见性及分享限制的处理，不丢已有资料。
