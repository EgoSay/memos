# 照片与录音原件、可选转写

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

照片与声音本身就是生活记录。显示版本或转写不应替代原件，也不应让权限失败阻止文字记录。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 支持照片或录音独立成条；照片有本地预览和上传状态，录音有开始、时长、停止、试听、取消。
- 私有原件保留原始字节，缩略图与兼容版本独立保存；梳理现有去 EXIF/重编码链路，不能承诺恢复历史上未保留的字节。
- 转写由本人单独触发，候选文字经检查后加入正文；保留来源关系，失败不删原音或阻断保存。
- 对外分享/同步使用受授权的媒体衍生版本，避免将原图 EXIF 等私有元数据隐式带出。

## UI 与交互规范

- 只有点击拍照、选图或录音时申请权限；拒绝后仍可写文字。
- 媒体不自动播放，失败显示具体可恢复动作。

## 验收条件

- [ ] 纯照片、纯录音均能保存、重开和使用；原文件可校验。
- [ ] 转写不使用、失败或取消时原件完整。
- [ ] 权限拒绝、上传中断和不兼容格式不导致输入消失。
- [ ] 区分旧媒体现状与新上传原件保证，不虚假标示原件。
