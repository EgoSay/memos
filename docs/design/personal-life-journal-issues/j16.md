# 可迁移导出、独立备份与无意外外发的恢复

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

十年后仍能读取和带走资料，不能只依赖一个运行中的应用；恢复旧备份也不能复活旧分享和社媒发布任务。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 导出可在应用外读取的正文、日期、元数据与受管理媒体，AI 独立标识；外链媒体无法保证时列出缺口。
- 默认导出不带草稿、最近删除、访问令牌、密钥或生效的外发配置。
- 独立备份数据库与媒体，保留周期/目的地/频率待确认；验证一致性并能在干净环境恢复。
- 恢复后分享与同步默认暂停，旧授权不自动复活、待发不重放；已发布映射可核查，恢复规则需明确动作。
- 导入保留来源和可知日期，未知不编造；不默认加入已有动态分享或同步回放。
- 说明自托管不等于端到端加密，以及独立备份保留的删除边界。

## UI 与交互规范

- 数据维护放设置，失败可见；恢复报告显示缺少媒体、跳过项目及需要重新启用的规则。

## 验收条件

- [ ] 导出离开应用仍能读正文及媒体，所有外链缺口可见。
- [ ] 在干净环境按步骤恢复并核对条数、内容、媒体和关系。
- [ ] 导入/恢复到已有启用实例不会扩大分享或自动发布。

关联总需求验收：AC20、AC21、AC36。这些是未来验收条件，当前没有勾选为完成。
