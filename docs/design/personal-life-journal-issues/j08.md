# 每日回顾：主动进入、同日稳定的旧记录

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

回顾应让旧日片段自然重现，而非每天必须完成的阅读任务。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 只有进入每日回顾才展示，打开应用或保存记录不自动展开。
- 建议最多三条、同一本地日跨设备稳定；优先一条往年同日，其余不同时间随机，候选不足不凑数。
- 候选为本人已保存已同步、早于今天、未删除未归档未排除的原始记录；不含草稿、评论、他人记录或单独 AI 输出。
- 删除/排除立即生效，宁可减少当日条数；跨午夜/时区不替换当前正在读的内容，下次进入刷新。
- 更多菜单可排除回顾及漫步，仍能主动搜索并恢复偏好。

## UI 与交互规范

- 显示日期、原文和手动播放的媒体；不先用 AI 总结。
- 无已读进度、完成按钮、感受提问或补看任务；详情返回保持原位。

## 验收条件

- [ ] 同日重复进入组内容稳定，无同日往年记录时自然随机退化。
- [ ] 零条/一条候选不虚构、不重复、不催促记录。
- [ ] 删除和排除马上从候选退出；恢复偏好可控。

关联总需求验收：AC04、AC05、AC06、AC08、AC15。这些是未来验收条件，当前没有勾选为完成。
