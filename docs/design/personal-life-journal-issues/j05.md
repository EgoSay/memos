# 编辑版本、最近删除与衍生内容清理

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

用户可以修改和删除真实记录，同时需要误操作恢复；归档不能冒充最近删除，衍生内容也不能继续泄露已删除原文。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 提供最近版本及最近删除，建议保留 30 天，期限须在评审后冻结；普通编辑不要求理由。
- 删除立即移出搜索、回顾、漫步和 AI 来源，清理可泄露内容的缓存和已保存 AI 衍生结果。
- 删除/归档撤销对应分享条目并停止待发正文和重试；已外发副本按独立撤回规则处理。
- 恢复记录不自动恢复旧分享授权或重新外发；彻底删除及备份保留边界有准确说明。

## UI 与交互规范

- 版本和恢复在次级入口，不反复强调改过；普通删除可撤销，彻底删除明确确认。
- 不能将本地删除显示成社媒和已下载副本都删除。

## 验收条件

- [ ] 恢复期内找回正确正文与媒体，过期及彻底删除行为一致。
- [ ] 删除后搜索、直接链接、AI 衍生结果、分享和待发队列均按权限规则失效。
- [ ] 恢复后本人可读，但先前对外授权不复活。

关联总需求验收：AC14、AC19、AC23。这些是未来验收条件，当前没有勾选为完成。
