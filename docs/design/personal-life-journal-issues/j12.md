# 访客只读页面、分享授权及媒体访问边界

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

分享范围只有在页面、接口、图片和附件都执行一致授权时才成立。隐藏入口或 noindex 不能代替访问控制。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 提供不可猜测只读链接，可配置提取码、期限、停用和重新生成；授权模式准确说明是链接持有者，不假称指定身份。
- 页面、API、缩略图、附件直链采用相同范围与撤销规则；停用/到期后旧访问路径失效。
- 访客只见本链接许可的正文、日期和媒体，不见全库搜索、私人标签目录、日历或其他记录数量。
- 分享媒体去除不必要 GPS/EXIF，内部引用不能跳入其他私密内容；外部嵌入不自动加载。
- 错误链接、错误提取码、无效或过期链接不能泄露记录是否存在或私人元信息。

## UI 与交互规范

- 访客页面安静只读、适配移动端；创建者可按相同授权预览。
- 提取码校验、失效和空分享有清楚状态；无点赞评论或访问分析。

## 验收条件

- [ ] 未授权、越界 ID、过期、撤销及旧附件直链均无法读取受保护内容。
- [ ] 访客预览与实际访客一致，截图/下载副本无法收回的边界不被夸大。
- [ ] 缓存、内部引用和外部媒体不绕过当前授权。
