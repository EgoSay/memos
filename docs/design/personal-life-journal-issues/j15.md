# 首个社媒目标接入与真实发布链路验证

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

Webhook 投递完成不能证明内容已经到社媒。用户预期的是指定分区内容能真实同步到所选平台。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 先确认首个社媒平台和接收服务，列出认证、文本、媒体、限额、更新与撤回能力；平台未选定时本议题保持待选型。
- 使用稳定事件及外部记录映射，保留原文；平台格式转换不得静默润色、截断或丢媒体。
- 接收有效发布回执及可核查外部链接；不支持更新/撤回时准确说明，不模拟成功。
- 真实外发测试仅在后续明确授权的目标账号与测试内容上执行，本轮只创建需求。

## UI 与交互规范

- 未支持能力清楚呈现，平台失败不损坏本地记录。
- 不增加流量建议、选题推荐、运营指标或分享催促。

## 验收条件

- [ ] 在首个真实平台核对文字和媒体的创建结果。
- [ ] 验证重复、更新、删除/撤回、失败与重试的实际支持边界。
- [ ] 没有发布回执时显示送达或未知；错误目标不会被标成已发布。

关联总需求验收：AC37、AC30、AC32。这些是未来验收条件，当前没有勾选为完成。
