# 保留活动日历数量着色与日期浏览

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

用户明确认可数量着色带来的轻微激励。需要保留积累的可见性，同时不引入连续目标或缺席压力。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 默认保留每日记录数量着色，复用现有 0–4 色阶基础；点击日期定位记录。
- 按记录日期和明确时区统计本人已保存、未删除原始记录；归档计入为建议默认，待评审。
- 每条只计一次；编辑、附件数、AI 结果、分享和同步副本不增加；导入归原日期。
- 明确全库或分区筛选范围，支持折叠、隐藏及关闭颜色；访客不能看到私人日历。

## UI 与交互规范

- 桌面侧栏可见，手机输入区之后紧凑展示，不能挤占输入首屏。
- 空白中性；不用断签、连续奖励或补记文案；日期和数量不能只靠颜色辨识。

## 验收条件

- [ ] 新增、补记、编辑、删除、恢复和导入后数量正确。
- [ ] 隐藏及颜色设置有效，键盘和非颜色信息可读。
- [ ] 数量反馈不会产生目标、通知或待办，访客无私人统计。

关联总需求验收：AC34、AC35。这些是未来验收条件，当前没有勾选为完成。
