# 草稿持久化、离线保存与同步冲突恢复

> 状态：需求已整理，待评审/实施；创建 issue 不代表具体默认值已全部通过，也不代表编码或真实外发已获批准。

产品总需求：[#1：完整 PRD](https://github.com/EgoSay/memos/issues/1)。对应本地 PRD v0.2；所有建议默认值服从总需求 R01–R09 的评审结果。

## 背景与目标

长期记录首先不能丢。当前保存文本与已上传附件引用的草稿方式不能证明未上传媒体在重启后仍可恢复。

## 产品与交互边界

这是本人长期、真实、轻松记录生活的工具。普通记录默认私密，探索主动进入；允许本人配置范围分享与分区自动同步，保留日历数量着色。不添加连续任务、强制整理、成长评价或社交运营目标。

## 功能需求

- 明确草稿、本地正式保存、待同步、同步中、完整同步、附件待重试、本地保存失败的状态。
- 在确认的目标浏览器上持久化正文和未上传媒体；重启、断网、配额不足时状态真实，不把内存暂存标成本地已保存。
- 草稿不进入正式列表、回顾、AI 或外发；只有显式保存形成正式记录。
- 稳定客户端标识防重复保存；正文成功附件失败仍为未完整同步，不触发外发。
- 多设备编辑保留双方冲突内容，由本人解决，不静默覆盖。

## UI 与交互规范

- 失败留住输入，可重试或复制；无需处理完成才能继续记别的内容。
- 恢复草稿不以未完成任务提示；返回页面维持编辑状态。

## 验收条件

- [ ] 断网录入正文和媒体后重启应用仍可恢复；恢复网络后完整同步。
- [ ] 超时重试及连续点击只形成一条记录。
- [ ] 附件部分失败清楚可见，普通记录不会因此丢失。
- [ ] 模拟两设备并发修改可找回两个版本；本地配额写入失败不会伪报成功。

关联总需求验收：AC16、AC17、AC18。这些是未来验收条件，当前没有勾选为完成。
